# 버튼·입력 동작표

[English](ACTIONS.md) · [처음으로](../README-KR.md)

실행 화면에는 링크처럼 보이는 자리표시자나 작동하지 않는 운영체제 장식 버튼을 남기지 않습니다. 아래 표는 실제 DOM과 이벤트 핸들러의 대응입니다.

| 항목 | 식별자 | 실제 동작 |
|---|---|---|
| EN / KR | `lang-en`, `lang-kr` | UI 언어를 직접 선택. 허용된 경우 localStorage 기록 |
| 이미지 열기 / 시작 화면의 열기 | `btn-upload-trigger`, `btn-drop-upload` | 로컬 이미지 파일 선택창 열기 |
| 이미지 저장 | `btn-export` | PNG/JPEG 저장 대화상자 열기 |
| 원본 비교 | `btn-compare` | 원본/가공 분할 보기와 비교 슬라이더 전환 |
| 효과 초기화 | `btn-reset` | 30개 효과와 노이즈 시드를 기본값으로 복구 |
| 테스트 패턴 | `btn-demo` | 브라우저 Canvas로 실제 진단 이미지 생성 |
| 도움말 | `btn-info` | 지원 범위·동작·개인정보·단축키 설명 열기 |
| PNG 공유 | `btn-share` | 파일 공유 지원 환경에서만 표시. PNG 파일을 만든 뒤 명시적 OS 공유 호출 |
| 원본 보기 / 가공 보기 | `btn-original` | 원본과 가공 표시 전환. 출력 이미지 자체는 변경하지 않음 |
| 화면 맞춤 / 확대 / 축소 | `btn-fit`, `btn-zoom-in`, `btn-zoom-out` | 현재 미리보기 변환값 조정 |
| 방향 버튼 | `data-dir` | 좁은 화면에서 미리보기 이동 |
| 효과 탭 | `property-tab-0` ~ `3` | 대응하는 실제 파라미터 페이지 선택 |
| 효과별 ? | `data-help` | 각 항목의 EN/KR 설명 표시. 재클릭·Esc·바깥 클릭으로 닫기 |
| 새 노이즈 | `btn-reseed` | 새로운 시드를 적용해 가공 결과 재계산 |
| 설정 열기 / 설정 저장 | `btn-settings-load`, `btn-settings-save` | 로컬 JSON 파일 선택 / 실제 JSON 파일 다운로드 |
| 저장 대화상자의 파일 저장 | `btn-download` | 최신 처리 결과를 기다려 실제 PNG/JPEG Blob 다운로드 |
| 저장 취소·닫기 / 도움말 확인·닫기 | `data-close` | 지정한 실제 대화상자 닫기 |
| 프리셋·해상도·시드 입력 | `preset-select`, `resolution-select`, `seed-input` | 값 적용 후 실제 픽셀 처리 |
| 30개 효과 입력 | `p_*` | 체크박스·범위 입력으로 효과 변경 및 재계산 |
| 비교·확대·저장 품질 | `compare-slider`, `zoom-slider`, `export-quality` | 분할 위치 / 확대 비율 / JPEG 출력 품질 변경 |

파일을 읽는 중이거나 이미지가 없으면 이미지 관련 명령을 비활성화합니다. JPEG, 링잉, 색 편향, 스캔라인 등을 끄면 해당 종속 수치 입력도 비활성화합니다. 이는 미구현 버튼이 아니라 현재 상태에서 사용할 수 없는 명령입니다.

UI에는 외부 웹 링크를 두지 않았습니다. 다운로드용 링크는 사용자가 저장을 누를 때 실제 Blob URL로 잠시 만들고 제거합니다. 문서의 상대 링크는 정적 검사로 대상을 확인합니다. 공유 목적지에서의 최종 전달은 운영체제와 대상 앱의 동작이며, 이번 환경에서는 실제 목적지를 검증하지 않았습니다.
