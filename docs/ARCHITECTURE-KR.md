# 구현 구성 / 2.1.0

[English](ARCHITECTURE.md) · [처음으로](../README-KR.md)

## 정적 시작과 파일 역할

`index.html`에서 CSS 두 개와 일반 `defer` 스크립트 여섯 개를 로드합니다. 순서는 `parameters`, `strings`, `engine`, `processor`, `demo`, `app`입니다. ES 모듈, 번들, 동적 import, CDN 요청은 없습니다. `css/windows95.css`는 제공된 원문이고 `css/app.css`가 페이지 배경·글꼴·레이아웃을 덮어씁니다. 창 관리용 `shell.js`는 없습니다.

배포 CSP는 동일 출처 스크립트, 좌표 지정에 필요한 인라인 스타일, Blob/data 이미지, Blob Worker만 허용하며 외부 통신과 폼 제출 등을 차단합니다. `unsafe-eval` 또는 인라인 스크립트 허가는 배포본에 없습니다. Worker는 이미 로드한 독립 커널 함수로부터 Blob으로 만들므로 추가 파일 요청이 없습니다. GitHub Pages에는 정적 파일만 필요합니다.

## 화면과 언어

메인 앱은 브라우저 너비를 채우고 바탕 화면과 OS 창 조작은 포함하지 않습니다. 큰 화면은 미리보기와 속성 패널을 별도 열에 고정합니다. 너비 920px 이하는 문서 흐름에 따라 수직으로 배치합니다. 처리 이미지의 크기·이동·확대만 Canvas 컨테이너에 적용하므로 앱 글자에 확대 변형이 걸리지 않습니다.

`strings.js`는 `ko`, `en` 두 사전을 제공합니다. 화면에는 KR과 EN으로 표시합니다. `applyLanguage()`는 명시적 텍스트 키와 ARIA 키를 적용하고 파라미터 레이블을 다시 구성합니다. 새 픽셀 처리는 요청하지 않으며 원본 파일명·선택 탭·설정·확대 상태를 유지합니다. 브라우저 저장소가 막혀도 언어 변경이 멈추지 않도록 접근 오류를 처리합니다. 기본 언어는 한국어이며 유효한 저장값이 있으면 복원합니다. 이전 `ja` 저장값은 한국어 기본값으로 돌아갑니다.

## 처리와 저장

원본 디코딩, 해상도 제한·검정 배경 합성, 선택적 실제 JPEG 재압축/디코딩 이후 기존 `engine.js`로 넘깁니다. 기존 커널은 명암·채널 조정, YIQ 분리, 휘도 링잉, 휘도·색차 대역 제한, 수직 색 번짐, 지터·행별 변위·잡음, RGB 복원 및 드롭아웃 등을 계산합니다. 2.1.0에서는 이 커널 파일의 바이트를 변경하지 않았습니다.

요청 버전을 비교해 최신 원본과 설정에 해당하는 처리만 반영합니다. 저장은 최신 결과를 기다린 뒤 별도 Canvas 복사본으로 PNG/JPEG를 생성합니다. 비교선·UI·확대 상태는 포함되지 않습니다. Blob Worker가 실패하면 원본 버퍼를 유지한 채 같은 커널을 메인 스레드에서 실행합니다.

설정 스키마는 `retro-video-effector/settings` version 2를 유지하고 `vhs-local-clone/settings` version 1도 읽습니다. 파라미터 범위 검증과 알 수 없는 키 무시는 기존 규칙을 유지합니다.

## 입력과 명령 가용성

`syncImageCommands()`는 이미지 존재·로딩·저장 상태를 기준으로 버튼을 비활성화합니다. 공유 버튼은 `navigator.share`와 파일용 `navigator.canShare` 확인 후 표시합니다. 플랫폼이 공유를 거부하면 저장 기능을 안내합니다. 일반 저장은 브라우저 다운로드이며 서버 업로드가 아닙니다. 이미지 바이트는 앱의 영속 저장소에 기록하지 않습니다.

## 검사 경계

[QA](QA-KR.md)는 실제 기능 실행과 브라우저 직접 탐색을 구분합니다. 관리자 정책으로 주소 탐색이 막힌 환경에서는 테스트 복사본을 메모리에 로드하며 이때만 인라인 스크립트를 허용합니다. 배포본의 CSP는 변경하지 않습니다. 이 검사를 GitHub Pages 게시 성공이나 네이티브 언어 설정 영속성의 증거로 설명하지 않습니다.
