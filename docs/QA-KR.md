## 실제 실행한 기능

실제 이미지 선택창 열기, 업로드된 파일 객체의 PNG 디코딩, Blob Worker 및 메인 스레드 대체 연산, 파라미터·프리셋·시드·해상도 변경, 최신 버전 반영, 원본·비교·확대·이동을 검사했습니다. PNG/JPEG와 JSON을 실제 다운로드 이벤트로 저장한 뒤 PNG/JPEG를 Pillow로 다시 열어 형식·크기를 확인했습니다. 원본 보기와 비교선을 켠 상태에서도 가공 PNG의 바이트가 그대로인지 검사했습니다.

EN/KR 전환 전후 파라미터, 픽셀, 활성 탭, 확대값, 유니코드 파일명이 보존되는지 확인했습니다. 두 사전의 키 대응, 모든 파라미터 설명, 텍스트·ARIA·툴팁·메타 키, 저장 형식, 오류·상태 문구를 검사했습니다. 화면의 한글 버튼은 이 환경에 설치된 Noto Sans CJK KR의 실제 글리프로 렌더링되었습니다. 앱 UI의 검사 대상 글자는 최소 14px이며 소스와 렌더링 텍스트에서 대체 문자 `�`가 없는 것을 확인했습니다. 이는 모든 운영체제에 한글 폰트가 설치돼 있다는 보장은 아닙니다.

1920×1080, 1440×900, 1024×768, 920×800, 768×1024, 390×844, 320×640 뷰포트에서 가로 넘침, 작은 글자, 고정 오버레이·드로어 부재를 검사했습니다. 작은 화면에서 테이프 하단 항목까지 스크롤해 조작했습니다. 개별 링크·버튼의 역할은 [동작표](ACTIONS-KR.md)에 있습니다.

## 직접 탐색과 인메모리 실행의 구분

이 환경에서는 실제 `file://` 및 브라우저 localhost HTTP 탐색이 모두 `ERR_BLOCKED_BY_ADMINISTRATOR`로 차단됐습니다. 브라우저 정책을 변경하거나 우회하지 않았습니다. 하네스는 이 실패를 기록한 뒤 허용된 인메모리 방식으로 실제 앱의 HTML/CSS/JS를 로드했습니다. 이 테스트 복사본에서만 인라인 스크립트를 허용하며 배포 `index.html`의 CSP는 바꾸지 않습니다.

따라서 브라우저에서 실제 Canvas·Worker·폰트·파일 다운로드가 실행됐지만, 배포본의 외부 스크립트 CSP를 HTTP origin에서 검증하거나 `index.html`을 직접 연 것은 아닙니다. 별도로 Python HTTP 서버와 클라이언트에서 저장소 하위 경로의 모든 런타임 자원을 요청해 상태 200, MIME, 디스크 파일과의 바이트 일치를 검사했습니다. 이를 실제 GitHub Pages 게시 검증으로 대체하지 않습니다.

## 모의 검사와 미검증 범위

언어 선택의 저장·복원 로직은 주입한 저장소 객체로 검사했고, 저장소 접근이 예외를 던져도 전환이 되는지 확인했습니다. **실제 origin의 localStorage에서 새로고침 후 영속 복원하는 경로는 미검증**입니다.

파일 공유의 미지원 숨김은 해당 Chromium의 실제 가용성을 바탕으로 검사했습니다. 지원 시 PNG File을 전달하는 분기는 모의 OS 수신 함수를 주입해 검사했습니다. **실제 공유 창과 외부 앱에 전달 완료는 미검증**입니다. 운영체제 정책, 권한, 사용자 활성 상태에 따라 공유가 거부될 수 있으며 앱은 실패를 안내합니다.

드롭·붙여넣기 입력 이벤트는 모의 이벤트로 발생시켰으나 이후 이미지 디코딩과 픽셀 처리는 실제 코드로 수행했습니다. Safari, Firefox, 실제 휴대전화·태블릿, 모든 입력 이미지 포맷과 기기 메모리 한계, 모든 보조공학 조합은 검증하지 않았습니다. 브라우저 확대 배율에 따른 모든 시스템 조합의 폰트 렌더링도 보장하지 않습니다.

## 재실행

앱은 빌드 없이 실행합니다. 개발자용 검사만 다음 명령을 사용합니다.

```text
node --test tests/engine.test.cjs
python tests/static.test.py
python tests/browser.test.py
```

브라우저 테스트는 먼저 실제 탐색을 시도하고 차단되면 실패 이유와 인메모리 사용을 JSON에 기록합니다. 결과와 다운로드는 `.test-output/`에 생성됩니다. 이 디렉터리는 배포 ZIP에 포함하지 않습니다.
