## 2.1.0 / 앱 단독 레이아웃

### 화면 정리

바탕 화면 제목과 바로가기, Start 버튼, 작업 표시줄, 시계, 앱의 최소화·최대화·닫기, 가짜 크기 조절 손잡이를 제거했습니다. 창 관리용 `js/shell.js`와 기존 `css/desktop.css`는 배포에서 제거했습니다. 앱은 페이지의 왼쪽 위에서 시작해 전체 너비를 사용합니다. 기존 남색 제목줄과 회색 입체 테두리는 내부 편집기에만 적용합니다.

도구 모음과 기능이 중복되는 메뉴 및 고정 속성 패널로 포커스만 보내던 속성 버튼도 제거했습니다. 이미지 열기·저장·비교·초기화·진단 패턴·도움말과 실제 파라미터 조절은 유지합니다. 공유 기능 미지원 시 공유 버튼은 표시하지 않습니다. 이미지가 없을 때 의미 없는 저장·비교·확대 기능은 비활성화합니다. PNG/JPEG 저장과 도움말의 닫기 버튼은 실제 대화상자를 닫으므로 유지합니다.

### 언어와 가독성

세 언어 순환 버튼을 EN / KR 직접 선택 버튼으로 교체했습니다. UI, 효과 설명, 접근성 이름, 저장 형식, 메타 설명, 처리 상태와 알려진 상태 알림을 번역합니다. 원본 파일을 연 뒤 언어를 바꾸면 파일명이 ‘이미지 없음’으로 덮이던 결함을 수정했습니다. 파라미터·이미지·활성 탭·확대 상태는 언어 전환 때 유지합니다.

UTF-8과 한글 지원 시스템 폰트 스택을 적용하고 고정폭 글꼴을 숫자·영문 워드마크로 제한했습니다. 10~13px UI 축소 규칙은 앱 스타일에서 제거했습니다. 본문 16px, 일반 항목 15px, 보조 텍스트 14px 이상으로 구성하고 모바일에서도 작게 줄이지 않습니다. 외부 폰트 로딩이나 폰트 파일 배포는 없습니다.

### 기능과 문서

기존 `engine.js`의 내용과 수치 처리를 그대로 유지합니다. 기존 30개 파라미터 계약과 4개 프리셋의 픽셀 회귀 기준도 유지합니다. 설정은 동일한 version 2 형식으로 저장하며 version 1도 읽습니다. 저장된 JSON의 `engine: rve-js-2.0.0`은 변경하지 않은 커널을 가리키며 UI 패키지 버전 2.1.0과 구분됩니다.

버튼 동작표, EN/KR README, 아키텍처, QA, 실행 캡처를 새 레이아웃에 맞춰 갱신했습니다. 과거 버전의 검사 결과를 새 버전의 검증으로 재사용하지 않았습니다.

## 2.0.0 / 이전 버전

제품명을 Retro Video Effector로 변경하고 Windows 95 템플릿, 고정 속성 탭, 복고풍 코드·주석, 정적 폴더 구조를 도입한 버전입니다. 이때 포함됐던 바탕 화면과 창 관리 구성은 2.1.0에서 제거됐습니다.
