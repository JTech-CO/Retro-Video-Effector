Retro Video Effector

VERSION 2.1.0

01 / 브라우저 내부 처리

Canvas와 JavaScript Web Worker로 이미지를 가공합니다. AI 모델, 외부 API, 이미지 업로드, 분석 스크립트, 원격 폰트를 사용하지 않습니다. 브라우저 저장소에는 언어 선택만 기록합니다. 이미지 공유 버튼은 파일 공유를 지원하는 환경에서만 표시하며, 사용자가 누를 때만 운영체제의 공유 기능을 호출합니다.

02 / 프로그램 정보

Retro Video Effector는 사진에 아날로그 영상 신호의 열화를 적용하는 정지 이미지 편집기입니다. Windows 95의 남색 제목줄과 입체 테두리만 사용하고 바탕 화면이나 운영체제 창은 모방하지 않습니다. 소스 주석은 C/BASIC풍이며, 실행에는 현대 브라우저가 필요합니다.

03 / 지원 범위

정지 이미지용입니다. 애니메이션은 정지 프레임으로 처리하며 움직임을 보존하지 않습니다. 투명 영역은 검정 배경에 합성합니다. 파일 최대 40MiB, 입력 최대 40MP, 출력 긴 변 최대 2560px 및 4MP입니다. HEIC·SVG·동영상은 지원하지 않습니다.

04 / 단축키

Ctrl/Command+O: 이미지 열기 / Ctrl/Command+S: 이미지 저장 / F: 화면 맞춤 / C: 비교 / Space 누름: 원본 / F1: 도움말 / Esc: 도움말·대화상자 닫기. 효과 탭은 방향키, Home, End로 이동할 수 있습니다.
